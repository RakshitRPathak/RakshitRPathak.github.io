minic

A dependency-free compiler for a small imperative language, going through the same stages as a production compiler.

Complete

The problem

Built to understand every stage between source text and execution, including the parts textbooks skip: error messages with line numbers, forward jumps, and keeping optimizations from changing behaviour.

How it works

  1. source
  2. lexer
  3. parser (AST)
  4. semantic analysis
  5. optimizer
  6. bytecode + backpatching
  7. stack VM
  • Hand-written lexer with one character of lookahead; recursive-descent parser building an AST.
  • Constant folding and dead-branch and dead-loop elimination. Folding shares its arithmetic code with the VM, so both agree on overflow and division.
  • Forward jumps are resolved by backpatching, the same problem linkers solve with relocations.
  • Semantic analysis runs before optimization, so removing dead code can never change which programs compile.
