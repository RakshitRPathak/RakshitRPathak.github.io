## How it's built

Plain HTML pages generated by a small Python script, with no framework and nothing to install. Content lives in one file, `data/site.json`; `build.py` turns it into a page per section and per project.

```bash
python3 build.py                 # regenerate every page after editing data/site.json
python3 -m http.server 8000      # preview at http://localhost:8000
```

Commit the generated pages along with your change; GitHub Pages serves them as they are.

```
data/site.json       all content: projects, patents, papers, experience, résumés, the hero chart
build.py             generates the pages below from data/site.json
assets/site.css      styles (light and dark)
assets/site.js       theme toggle, phone menu, project filter, copy email
index.html           home page             (generated)
projects/…           project index + one page per project (generated)
research/, experience/, resumes/, contact/   (generated)
404.html, sitemap.xml, robots.txt            (generated)
resume/              one-page PDF résumés
```

Links from the old single-page site (for example `/#p-ptxforge`) redirect to the new pages. The site follows the system light or dark theme with a toggle in the header, works at phone width, and respects reduced-motion settings.
